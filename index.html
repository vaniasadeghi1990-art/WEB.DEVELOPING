Flexbox & Responsive Web Design

A simple guide to how CSS Flexbox can arrange content, images and information on a web page.

Explore the layout

How the content is laid out

This page uses CSS Flexbox for the main content cards. The cards are placed in a row when enough horizontal space is available. When the screen becomes smaller, the cards wrap onto new rows.

HTML

HTML provides the structure of the web page, including headings, paragraphs, images and links.

CSS

CSS controls presentation, design and layout. It can also create different layouts for different screen sizes.

Flexbox

Flexbox makes it easier to arrange elements in rows or columns and control their alignment and spacing.

Important Flexbox settings

display: flex

Turns an element into a flex container. Its direct child elements become flex items.

flex-direction

Controls the direction of the flex items. Common values are row and column.

flex-wrap

Allows items to move onto a new line when there is not enough space. This page uses wrap.

justify-content

Controls the alignment of items along the main axis, for example space-between.

align-items

Controls alignment along the cross axis, such as center.

gap

Adds consistent space between flex items without needing separate margins on every item.

How the layout responds to screen size

The page is responsive. The viewport meta tag allows the layout to use the device width. Flexbox wrapping lets the cards move to new rows, while a media query changes the navigation and hero layout on smaller screens.

Large screen
3 cards can fit in a row.
Medium screen
Cards can wrap.
Small screen
Content becomes one column.

Flexbox features and how to use them

  • Flex container: add display: flex; to the parent.
  • Direction: use flex-direction to choose a row or column.
  • Wrapping: use flex-wrap: wrap; when items should move to another line.
  • Alignment: use justify-content and align-items.
  • Spacing: use gap to create space between items.
  • Flexibility: flex items can grow or shrink depending on the available space.
